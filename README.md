# Portafolio — Diego Bonilla Mora

Portafolio personal desarrollado con **HTML, CSS y JavaScript puro** (sin frameworks). Muestra mis habilidades como Frontend Developer, proyectos realizados e información de contacto.

## Vista previa

> Abre `index.html` directamente en el navegador o usa una extensión como **Live Server** en VS Code.

## Estructura del proyecto

```
portafolio/
├── index.html              # Página principal del portafolio
├── css/
│   └── styles.css          # Todos los estilos (variables, animaciones, responsive)
├── js/
│   └── main.js             # Interactividad (navbar, scroll reveal, animaciones)
├── img/
│   ├── yo.png              # Foto de perfil (hero)
│   └── programando.png     # Foto sección "Sobre mí"
└── proyectos/
    ├── proyecto1.html      # Restaurante Amanecer Dorado
    ├── proyecto2.html      # MundoTech — empresa de tecnología
    └── proyecto3.html      # Clínica Dental Sonrisa Perfecta
```

## Secciones

| Sección | Descripción |
|---|---|
| **Hero** | Presentación con foto, título y disponibilidad freelance |
| **Sobre mí** | Información personal, idiomas y foto |
| **Skills** | Habilidades técnicas con tarjetas animadas |
| **Proyectos** | Tres proyectos con links a páginas individuales |
| **Contacto** | Links a GitHub, LinkedIn y email |

## Proyectos incluidos

1. **Restaurante Amanecer Dorado** — sitio web de restaurante costarricense con menú interactivo y formulario de reservaciones (tema dorado/ámbar)
2. **MundoTech** — sitio corporativo de empresa tech con catálogo de servicios y productos (tema oscuro/cian)
3. **Clínica Dental Sonrisa Perfecta** — sitio de clínica dental con agenda de citas y catálogo de tratamientos (tema claro/teal)

## Tecnologías usadas

- **HTML5** semántico
- **CSS3** — variables, flexbox, grid, animaciones, glassmorphism
- **JavaScript ES6+** — IntersectionObserver, animaciones de scroll, hamburger menu
- **Google Fonts** — Inter, Space Grotesk, Nunito, Playfair Display

## Características

- ✅ Diseño completamente responsive (mobile, tablet, desktop)
- ✅ Animaciones de entrada con scroll reveal
- ✅ Navbar con efecto glassmorphism al hacer scroll
- ✅ Hero con anillo giratorio animado
- ✅ Tarjetas de skills con efecto glow
- ✅ Tres páginas de proyecto independientes con temas visuales únicos

## Cómo usar

1. Clona o descarga el repositorio
2. Abre `index.html` en tu navegador
3. No requiere instalación de dependencias ni servidor
