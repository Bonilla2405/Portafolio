## 🎯 Perfil Profesional Objetivo

**Frontend Developer & Web Performance Specialist**

Un desarrollador frontend que construye experiencias digitales con tres ejes simultáneos:

1. **Código limpio y estructurado** — HTML semántico, CSS mantenible, JavaScript justificado
2. **SEO técnico integrado** — cada sitio nace optimizado, no se optimiza después
3. **Criterio visual y UX** — capacidad de mejorar lo que se diseña, no solo ejecutarlo

El mercado no busca solo un desarrollador técnico, ni solo un diseñador. Busca un perfil que combine código sólido, criterio visual y comprensión de métricas.

##  Diferenciadores Clave

### 1. SEO técnico integrado al desarrollo
La mayoría de desarrolladores frontend no piensan en SEO mientras codean. Este perfil construye sitios donde la optimización es parte del proceso desde el inicio: estructura de encabezados, URLs limpias, meta tags, velocidad y Schema markup. 

### 2. Traducción diseño → código con criterio propio
No solo ejecutar un archivo Figma, sino tener criterio sobre UX, accesibilidad, animaciones y performance. La oferta 3 lo llama *"ojo de agencia"*, la oferta 2 lo llama *"CRO mindset"*. Es la diferencia entre un desarrollador que construye lo que le piden y uno que mejora lo que le piden.
